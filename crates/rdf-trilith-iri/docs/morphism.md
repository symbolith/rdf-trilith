# Morphisms

Every type is a `#[repr(transparent)]` newtype over `str`, so a value that satisfies a narrower grammar also satisfies every broader one, and every URI is a valid IRI. The impls are generated by rdf-trilith-macro-validated's `morphism!` ([validated.md](../../rdf-trilith-macro-validated/docs/validated.md)); the full invocation list (the transitive closure of the widening lattice) lives in the `morphism!` block in [iri.rs](../src/iri.rs).

Coercions reinterpret the same bytes in place via pointer cast; conversions move or create ownership.

|                        | Coercion            | Conversion            |
|------------------------|---------------------|-----------------------|
| Infallible (widening)  | `AsRef`             | `From`/`Into`         |
| Fallible (narrowing)   | `TryFrom<&Broader>` | `TryFrom<BroaderBuf>` |

## Infallible

Narrower → Broader

```
UriNormalized
├─→ Uri
│   ├─→ Iri
│   │   └─→ IriReference
│   └─→ UriReference
│       └─→ IriReference
└─→ IriNormalized
    └─→ Iri
        └─→ IriReference

UriAbsolute
├─→ Uri
│   ├─→ Iri
│   │   └─→ IriReference
│   └─→ UriReference
│       └─→ IriReference
└─→ IriAbsolute
    └─→ Iri
        └─→ IriReference

UriRelative
├─→ UriReference
│   └─→ IriReference
└─→ IriRelative
    └─→ IriReference
```

The transitive closure is derived hop by hop in [hops-asref.md](hops-asref.md).

### Coercions

Rust doesn't auto-chain [`AsRef`](https://doc.rust-lang.org/std/convert/trait.AsRef.html), so every transitive target needs an explicit impl.

```
Narrower     -AsRef→ Broader       (pointer cast, no alloc)
NarrowerBuf  -AsRef→ Broader       (pointer cast via Deref, no alloc)
```

### Ownership

```
TypeBuf      -AsRef→ Type          (pointer cast, no alloc)
```

### Conversions

```
NarrowerBuf -Into→ BroaderBuf     (no realloc)
```

## Fallible

Broader → Narrower

```
IriReference
├─→ Iri
│   ├─→ IriNormalized
│   │   └─→ UriNormalized
│   ├─→ IriAbsolute
│   │   └─→ UriAbsolute
│   └─→ Uri
│       ├─→ UriNormalized
│       └─→ UriAbsolute
├─→ IriRelative
│   └─→ UriRelative
└─→ UriReference
    ├─→ Uri
    │   ├─→ UriNormalized
    │   └─→ UriAbsolute
    └─→ UriRelative
```

### Coercions

```
&Broader   -TryFrom→ Result<&Narrower, E>      (validates, no alloc, pointer cast on success)
```

### Conversions

```
BroaderBuf -TryFrom→ Result<NarrowerBuf, E>    (validates, no realloc)
```
