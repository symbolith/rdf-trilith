# Edges

`Subject`, `Object`, and `Term` are enums over the term types: widening constructs a value, narrowing matches on the discriminant. The impls are generated by macro-enum-dr's `morphism!` ([enum.md](../../macro-enum-dr/docs/enum.md)). `LiteralBuf` is an alias for `Literal` ([rdf-12.md](rdf-12.md)). The owned edges mirror the borrowed ones with `Buf` names.

|                  | Widening (infallible)                     | Narrowing (fallible)                |
|------------------|-------------------------------------------|-------------------------------------|
| Variant ↔ enum   | `From` / `Into`                           | `as_variant()` / `into_variant()`   |
| Enum ↔ enum      | `From` / `Into`                           | `as_narrower()` / `into_narrower()` |
| Borrowed ↔ owned | `Into` both directions (owning allocates) | none, both ways always succeed      |

## Infallible

Narrower → Broader

### Variant ↔ Enum

```
Iri                IriNormalized      IriAbsolute        BlankNode          Literal
├─> Subject        ├─> Subject        ├─> Subject        ├─> Subject        ├─> Object
├─> Object         ├─> Object         ├─> Object         ├─> Object         └─> Term
└─> Term           └─> Term           └─> Term           └─> Term
```

```
&Variant    -Into→  Enum       (tag + fat pointer)
VariantBuf  -Into→  EnumBuf    (moves, no realloc)
```

### Enum ↔ Enum

```
Subject
└─> Object
    └─> Term
```

```
NarrowerEnum     -Into→  BroaderEnum       (variant remap)
NarrowerEnumBuf  -Into→  BroaderEnumBuf    (variant remap, moves)
```

### Borrowed ↔ Owned

```
&EnumBuf  -Into→  Enum       (tag + fat pointer)
Enum      -Into→  EnumBuf    (allocates)
```

## Fallible

Broader → Narrower

### Variant ↔ Enum

```
Subject            Object             Term
├─> Iri            ├─> Iri            ├─> Iri
└─> BlankNode      ├─> BlankNode      ├─> BlankNode
                   └─> Literal        └─> Literal
```

```
Enum     -as_variant→    Option<&Variant>      (match, free)
EnumBuf  -into_variant→  Option<VariantBuf>    (match, moves)
```

### Enum ↔ Enum

```
Term
└─> Object
    └─> Subject
```

```
Broader     -as_narrower→    Option<Narrower>       (variant remap)
BroaderBuf  -into_narrower→  Option<NarrowerBuf>    (variant remap, moves)
```
